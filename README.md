# TypeScript Assignment - Advanced Problem Solving with OOP

## Project Overview

This repository contains solutions for the TypeScript assignment focused on:

* Basic TypeScript problem solving
* Object-Oriented Programming (OOP)
* Interfaces and Generics
* Type Guards and Union Types

## Files Included

* `solutions.ts` → Contains all coding solutions
* `blog-1.md` → Blog post 1
* `blog-2.md` → Blog post 2
* `README.md` → Project overview

## Technologies Used

* TypeScript
* Node.js

## How to Run

1. Install TypeScript globally:

```bash
npm install -g typescript
```

2. Compile the TypeScript file:

```bash
tsc solutions.ts
```

3. Run the generated JavaScript file:

```bash
node solutions.js
```
